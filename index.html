Inventaria System

Inventário de almoxarifado sem papel: importa a planilha do Excel, faz a contagem pelo celular com leitor de código de barras e gera a recontagem só dos itens que divergiram.

  • Estado calculado a partir de uma sequência de eventos, com histórico de quem lançou o quê
  • Código de barras Code 128 gerado do zero em SVG
  • Aponta possíveis trocas de código comparando as descrições dos itens
  • HTML
  • CSS
  • JavaScript
  • SheetJS
  • ZXing

PRF Aprova

Plataforma de estudos para o concurso da Polícia Rodoviária Federal que funciona sem internet: questões no estilo Cebraspe, simulados, flashcards e cronograma semanal.

  • Funciona offline como aplicativo instalável (PWA)
  • Flashcards com repetição espaçada pelo algoritmo SM-2
  • Script em Node.js empacota tudo em um único arquivo HTML

uso interno · rede da empresa
C4 · Python + SQLUso interno

Sistema de almoxarifado

Sistema web para o almoxarifado de uma empresa do setor elétrico: requisições das equipes de campo, entrega de EPI com validade de CA, cautelas e painel de indicadores.

  • Back-end em Flask com SQLite e VIEWs para calcular saldos
  • Sete perfis de acesso, PIN guardado como hash e bloqueio após tentativas erradas
  • O celular continua lançando sem rede e sincroniza quando a conexão volta
  • Python
  • Flask
  • SQLite
  • SQL
  • JavaScript
